## Looked at and left out

- **Tinkercad Circuits**: no ESP32.
- **Velxio**: open source and can be self-hosted, but a reviewer's ESP32 builds failed in April 2026.
- **Hugging Face Spaces**, for hosting: the kind we would need is no longer free.

Where to host the backend is a separate question, answered in the repository's
`ai-docs/research/` notes.
