# Flash it

Write the firmware to a board from this page, over USB. No software to install: Chrome, Edge or Firefox on a computer.

Each button holds two images: one for the **ESP8266 NodeMCU** you have, and one for an
ESP32 DevKit. The page asks the board which chip it is and writes the right one.

1. **Plug the NodeMCU in** with a USB cable that carries data. A charge-only cable is the most common reason a board is not found.
2. **Press Install** and pick the board's port. Yours has a CH340 USB chip, so the port is named after it. No port at all: Windows may need the CH340 driver from the chip's maker, WCH.
3. **If it will not connect**, hold the board's FLASH button, press and let go of RST, then let go of FLASH.
4. **When it is done**, the display shows `NOT CALIBRATED` (the real build) or a weight (the pretend one), and the serial line prints `E boot node=a fw=0.2.0`.

<Callout type="caution" title="Not yet tried on a board">

The images were built with PlatformIO on 23 October 2026. The ESP32 images were checked
piece by piece against the addresses PlatformIO writes; the ESP8266 image is
PlatformIO's own file, written at address 0 as its upload does. None has been flashed
to a board yet. If the page fails, flash from `firmware/node-a-scale` with
`pio run -e node-a-nodemcu -t upload`.

</Callout>

Plug the camera in through its MB base. If it will not connect, hold the base's IO0
button, press RST, then let go of IO0. When it is done the serial line prints
`E boot node=b`, then `wifi not-set` until the Wi-Fi is set.

## Where these files come from

`firmware/tools/publish_web.py` builds them all, joins each into one image starting at
address 0, and writes them into the site with the version from the firmware. Run it
after any change to the firmware, and commit what it writes.
