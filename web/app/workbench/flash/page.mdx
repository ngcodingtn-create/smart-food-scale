# Flash it

Write the firmware to a board from this page, over USB. No software to install: Chrome, Edge or Firefox on a computer.

1. **Plug the DevKit in** with a USB cable that carries data. A charge-only cable is the most common reason a board is not found.
2. **Press Install** and pick the board's port. It is named after the board's USB chip: CP210x or CH340.
3. **If it will not connect**, hold the board's BOOT button while it starts to write.
4. **When it is done**, the display shows `NOT CALIBRATED` (the real build) or a weight (the pretend one), and the serial line prints `E boot fw=0.1.0`.

<Callout type="caution" title="Not yet tried on a board">

All three images were built with PlatformIO on 14 October 2026 and checked piece by piece:
the bootloader, partition table and program sit at the addresses PlatformIO itself
writes. Nobody has flashed them to a board, because there is no board yet. If the
page fails, flash from the board's folder under `firmware/` with `pio run -t upload`.

</Callout>

Plug the camera in through its MB base. If it will not connect, hold the base's IO0
button, press RST, then let go of IO0. When it is done the serial line prints
`E boot node=b`, then `wifi not-set` until the Wi-Fi is set.

## Where these files come from

`firmware/tools/publish_web.py` builds them all, joins each into one image starting at
address 0, and writes them into the site with the version from the firmware. Run it
after any change to the firmware, and commit what it writes.
