## The scale's firmware

Node A's real firmware on a simulated DevKit, load cell, display, two buttons and
buzzer. The same code that goes on the board, with the pins from the
[wiring](/workbench/wire); only the load cell's scale and the buzzer's transistor
differ, and the sketch says so at the top.

<WokwiFiles />

What it did on 14 October 2026, run this way: it compiled and booted, reported
`calibrated=1 cpg=0.42` (Wokwi's cell), searched channels 1 to 13 for the camera and
said `link none`, which is right: there is no Node B in a one-board simulation. With
0.42 kg on the cell (a plate) it read 176 counts, shown as 419.0 g. TARE set the
offset to 176 and the display to 0.0 g. At 0.57 kg (plate and food), PHOTO took twelve
readings of 239 counts, kept the median, and printed `g=150.0`; then it looked for the
camera again, found none, and reported `ok=0`. It ran at 1 to 10 % of real time there,
so each step took a minute or more.

To run inside this page instead, the project has to be saved under a Wokwi account,
which is the owner's to make. Its address then goes in `WokwiFiles.tsx`.
